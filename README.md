# **ARYLIC AMP BOARD WIFI SETUP**
You can use the arilyc_wifi_setup.py file to setup your WIFI on your amp board. Simply download to a windows computer and from the Command Prompt run Python3 arilyc_wifi_setup.py and a Window will open allowing you to choose your WIFI network and enter your password.
